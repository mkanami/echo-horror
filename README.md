# ЭХО

Хоррор от первого лица в браузере. Ты слепой оператор-слухач на подземном объекте «Камертон», 1987 год. Видишь только то, что звучит: каждый шаг, стук трости и всплеск разворачивается волной по стенам. Что-то в темноте охотится на звук.

**Исходная опубликованная игра:** https://tg-prplx.github.io/echo-horror/
Версия с главой II запускается локально командами из раздела «Запуск локально».

Перед началом — экран с рекомендацией наушников и предупреждением о резких звуках и вспышках. В меню доступны настройки звука, мыши и графики, управление и титры. Текстуры и звуки загружаются с отдельным индикатором прогресса.

Игра сохраняет прогресс в контрольных точках. «Продолжить» возвращает к последней из них; новая игра запрашивает подтверждение перед заменой сохранения.

## Глава II — «Ниже тишины»

После закрытия лифта первая глава продолжается спуском на горизонт −11.
Кабина переносится из первой главы целиком: исходные меши, материалы,
створки, дверная рама, поручни, кнопка и рифлёный пол. При переходе сохраняется
положение игрока относительно кабины; отдельной новой модели лифта нет.
Кабина резко останавливается; удержание **E** раздвигает створки обеими руками.
Отпущенная створка остаётся на защёлке — продолжить можно с достигнутого положения.

Для отдельного запуска выберите **«Горизонт −11»** в главном меню.
Этот запуск начинает новое сохранение с движения лифта вниз.

Новый уровень — преимущественно пещеры, в которые вросли палаты и оборудование:
каменный приёмник, затопленная перевязочная, «Хор пустых коек» над провалом,
палата 0, соляное горло и нижняя штольня. У провала два обхода; есть низкий
тихий лаз, подвешенные койки и палата, продолжающаяся по вертикальной стене.
Откройте дренаж, настройте резонатор и доберитесь до затвора нижней штольни.
После дренажа на новом горизонте появляется преследователь.

Под тремя кроватями на полу можно спрятаться по **E** и выбраться повторным
нажатием. Камера опускается к полу; монстр ищет укрытия и слышит дыхание,
как в первой главе. **Q / ПКМ** — задержать дыхание. Подвешенные кровати
и кровати на вертикальной стене остаются декорациями.

У провала нет невидимых стен для игрока: шаг за край приводит к падению
и смерти. Повтор возвращает к последней контрольной точке. Преследователь
строит путь по обходам; край удерживает его также при рывке и принюхивании.

Оформление продолжает первую главу: те же модели коек и медицинских деталей,
грязная эмаль, ткань, трубопроводы, бумага, подтёки и плесень. Их материалы
используют новые карты из `public/tex/cave/`. Баланс яркости пола, ткани и металла
совпадает с первой частью; пространство проявляется звуком. Таблички также
видны через эхо. Капли, искры и фон используют общий обработчик первой главы;
подсказки, цели и названия помещений выводятся её обычным интерфейсом.

Все **24 PBR-материала / 72 карты** новой зоны самостоятельные, 512×512:
камень, сланец, натёки, кальцит, соль, глина, ил, водоросли, окисленный металл,
эмаль, ткань и новая керамика. **12 типов составных моделей, 45 размещённых
объектов** созданы для этого уровня. Текстуры воспроизводятся командой
`python tools/generate-cave-materials.py` (нужны numpy и Pillow).

Контрольные точки сохраняются после открытия лифта, дренажа и настройки
резонатора; «Продолжить» и повтор после смерти возвращают в нужную главу.
Пауза останавливает спуск, работу руками и все игровые таймеры.

Проверки: `node --test tests/*.test.js`; сборка: `npm run build`.
Браузерная проверка: запустить `npm run build` и `npm run preview -- --port 4173`,
затем `node tools/verify-cave.cjs` (Playwright и установленный Chrome;
`PLAYWRIGHT_MODULE` позволяет указать путь к Playwright).

## Управление

| | |
|---|---|
| WASD | идти |
| Shift | бежать (громко) |
| C | красться (тихо) |
| F | стук тростью — осмотреться |
| Q / ПКМ | задержать дыхание |
| ЛКМ | бросить камень |
| E | взаимодействие (некоторое — удерживать) |
| V | вслушаться: замереть и понять, откуда идёт звук |
| 1 / 2 / 3 | заслонки перехода / люка / служебной двери (в лифтовом холле) |
| 4 | сейсмодатчик |
| Подойти вплотную лицом к заслонке | автоматически подпирать рукой; у люка — присесть |
| Esc | пауза |

## Запуск локально

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Технологии

three.js, Web Audio API (HRTF, свёрточная реверберация), Vite. Освещение — собственный шейдер «эхо-волн» поверх трипланарных PBR-текстур.

На телефоне игра работает в горизонтальном положении. Слева — аналоговый джойстик, по свободной части экрана можно осматриваться. «Действие», «Не дышать», «Слушать» и «Бег» работают при удержании; «Тихо» переключает приседание. У лифта появляются кнопки трёх заслонок и датчика. При повороте телефона вертикально игра ставится на паузу. Сенсорные кнопки проходят через тот же CRT, что и мир; зоны касания учитывают изгиб стекла.

Рендер отсеивает статические участки за постоянными стенами и вне камеры, сохраняя исходные треугольники, материалы и выбранные эффекты. Оптимизация не переключает качество и не уменьшает разрешение автоматически.
